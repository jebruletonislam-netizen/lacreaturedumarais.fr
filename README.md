# La Créature du Marais — site officiel

Site statique prêt pour GitHub Pages.

1. Créez un dépôt public GitHub.
2. Envoyez ces fichiers à la branche `main`.
3. Settings → Pages → Deploy from branch → `main` → `/root`.
4. Custom domain → `lacreaturedumarais.fr`.
5. Configurez les DNS GitHub Pages chez votre registrar.
6. Activez HTTPS.
